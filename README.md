# serial-merge

Скрипт для двох Excel-таблиць із серійниками. Для кожного серійника з другої таблиці він знаходить
відповідний рядок у першій і записує значення з неї. Результат зберігається як третій, уже
заповнений файл. Працює як `ВПР` / `INDEX + MATCH` в Excel, але без формул і без посилань між
файлами.

## Що робить

**Файл №1** — довідник. Стовпець A — серійник, B — кількість, C — втрачено. У кожному рядку
заповнене щось одне: B або C.

| Серийник | Количество | Потеряно |
|---------:|-----------:|---------:|
| 2222     | 1          |          |
| 4444     |            | 1        |
| 1111     | 2          |          |
| 3333     | 1          |          |
| 1111     | 5          |          |

**Файл №2** — список серійників, для яких треба заповнити стовпець B.

| Серийник | Количество |
|---------:|-----------:|
| 1111     |            |
| 2222     |            |
| 3333     |            |
| 4444     |            |
| 9999     |            |

**Результат (`3.xlsx`)** — копія файлу №2 із заповненим стовпцем B:

| Серийник | Количество |
|---------:|-----------:|
| 1111     | 2          |
| 2222     | 1          |
| 3333     | 1          |
| 4444     | 1          |
| 9999     |            |

`4444` отримав `1` зі стовпця «Потеряно», бо «Количество» в нього порожнє. `1111` трапляється у
файлі №1 двічі, тому взято перший рядок (`2`, а не `5`). `9999` у файлі №1 немає, тому клітинка
лишилася порожньою.

## Встановлення

Потрібен Python 3.8 або новіший.

```bash
git clone https://github.com/exxmanster/serial-merge.git
cd serial-merge
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

На Windows замість `.venv/bin/` пишіть `.venv\Scripts\`.

## Запуск

```bash
.venv/bin/python merge_serials.py 1.xlsx 2.xlsx
```

Результат з'явиться як `3.xlsx` поруч із файлом №2. Щоб зберегти під іншим ім'ям, вкажіть його
третім аргументом:

```bash
.venv/bin/python merge_serials.py 1.xlsx 2.xlsx результат.xlsx
```

| Аргумент      | Що це                                                             |
|---------------|-------------------------------------------------------------------|
| `source`      | файл №1, довідник: A — серійник, B — кількість, C — втрачено       |
| `target`      | файл №2: у стовпці A серійники, стовпець B буде заповнено          |
| `output`      | куди зберегти результат; типово `3.xlsx` поруч із файлом №2        |
| `-f, --force` | перезаписати `output`, якщо такий файл уже існує                  |

Після роботи скрипт виводить короткий звіт:

```
Готово: 3.xlsx
Знайдено: 4, не знайдено: 1
Немає у файлі №1: 9999
Дублі у файлі №1 (узято перший рядок): 1111
```

## Правила

- **B або C.** Береться значення з B. Якщо B порожній, береться C.
- **Не знайдено.** Якщо серійника немає у файлі №1, клітинка B у результаті порожня, навіть якщо
  у файлі №2 там уже щось було.
- **Порівняння серійників.** `1111`, `"1111"`, `1111.0` і `" 1111 "` вважаються одним серійником,
  тож байдуже, чи збережений він як число, чи як текст.
- **Дублі.** Якщо серійник трапляється у файлі №1 кілька разів, береться перший рядок, як у
  `ПОИСКПОЗ` / `MATCH`. Дублі перелічуються у звіті.
- **Аркуш і заголовки.** Читається активний аркуш кожного файлу (той, що відкривається першим);
  рядок 1 вважається заголовком і пропускається.
- **Безпечно для вхідних файлів.** Файли №1 і №2 не змінюються. Форматування файлу №2 переходить у
  результат. Наявний файл результату не перезаписується без `--force`.

## Обмеження

- Стовпці фіксовані: A, B, C у файлі №1 і A, B у файлі №2.
- У результаті записані значення, а не формули: якщо файл №1 зміниться, скрипт треба запустити ще раз.
- З результату не видно, звідки взялося значення, з «Количество» чи з «Потеряно».

## Без Python: формула для Excel

Те саме можна зробити формулою в самому файлі №2. Вставте її в B2, коли обидва файли відкриті, і
протягніть донизу.

Excel російською чи українською:

```
=ЕСЛИОШИБКА(ЕСЛИ(ИНДЕКС([1.xlsx]Лист1!$B:$B;ПОИСКПОЗ(A2;[1.xlsx]Лист1!$A:$A;0))<>"";ИНДЕКС([1.xlsx]Лист1!$B:$B;ПОИСКПОЗ(A2;[1.xlsx]Лист1!$A:$A;0));ИНДЕКС([1.xlsx]Лист1!$C:$C;ПОИСКПОЗ(A2;[1.xlsx]Лист1!$A:$A;0)));"")
```

Excel англійською:

```
=IFERROR(IF(INDEX([1.xlsx]Лист1!$B:$B,MATCH(A2,[1.xlsx]Лист1!$A:$A,0))<>"",INDEX([1.xlsx]Лист1!$B:$B,MATCH(A2,[1.xlsx]Лист1!$A:$A,0)),INDEX([1.xlsx]Лист1!$C:$C,MATCH(A2,[1.xlsx]Лист1!$A:$A,0))),"")
```

`[1.xlsx]Лист1` — ім'я файлу №1 і його аркуша; якщо у вас вони інші, замініть.
